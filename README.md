# Engviora by iEngels

Mirror your iPhone, iPad or Android screen to your Windows PC and use it as a source in OBS, Streamlabs, TikTok Live Studio and more.

Downloads are on the [Releases](https://github.com/engelsoc/engviora/releases) page: the Windows installer, a portable exe, and the exact source code of each version (GPL-3.0).

---

Duplica la pantalla de tu iPhone, iPad o Android en tu PC con Windows y úsala como fuente en OBS, Streamlabs, TikTok Live Studio y más. Las descargas están en [Releases](https://github.com/engelsoc/engviora/releases).
