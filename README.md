# EnStream.Live by iEngels

Mirror your iPhone, iPad or Android screen to your Windows PC — over Wi-Fi or a USB cable — and use it as a source in OBS, Streamlabs, TikTok LIVE Studio and more.

- iPhone and iPad over Wi-Fi (AirPlay) or USB cable, with sound; no developer mode.
- Android with the free EnStream.Live app (Android 10+), over Wi-Fi or USB tethering.
- Up to 120/144 fps with extra frames, sharpness and the Realce look, colour filters, logos and overlays, a privacy screen, recording and instant replay.

Downloads are on the [Releases](https://github.com/engelsoc/enstream-live/releases) page: the Windows installer, a portable exe, the Android app (APK), and the exact source code of each version (GPL-3.0).
